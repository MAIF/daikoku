# First run

Now that you have your own distro of Daikoku, it's time to run it. 

But before doing so, you'll need to make a few choices about some essential stuff in order to have the version of Daikoku which suits to your needs.

Let's start with the datastore !

For automated setup, see [Initialize Daikoku](./initialization.md): it explains how to seed the default tenant and administrator using environment variables, or import an existing state, and why these settings apply only to an empty datastore.
